# Jingzhi (Connie) Yang — Portfolio

A personal portfolio focused on product, analytics, and growth decisions.

The website is static HTML, CSS, and JavaScript, with no installation or external runtime dependencies.

## Preview locally

```sh
python3 -m http.server 8765
```

Open `http://localhost:8765/`.

## Contents

- Home and About
- Selected Work with Product, Analytics, and Growth filters
- CollegeBot, Amplify, Storyblocks, APSolway, Balenciaga, and Qeelin case studies

GitHub Pages publishes the public website from the main branch through the repository's deployment workflow. Local editorial notes, unused source materials, and unlisted cases are excluded from this repository.
